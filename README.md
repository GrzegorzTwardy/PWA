#### Opis aplikacji

Użytkownicy aplikacji mają dostęp do kamerki i mapy. Za pomocą pierwszej robią zdjęcie zgłaszanego zdarzenia, a za pomocą mapy mogą w prosty sposób wyznaczyć lokalizację zdarzenia. Po kliknięciu właściwego przycisku zdarzenie da się udostępnić do dowolnego użytkownika internetu.
